## ☁️ How to Build & Render on GitHub Cloud

Render the entire 60 FPS video directly in the cloud using GitHub Actions:

1. Open **[https://github.com/whispererofenigma/nifty-darwin/actions](https://github.com/whispererofenigma/nifty-darwin/actions)**.
2. Select **Build & Render 60FPS Remotion Reel (Cloud)**.
3. Click **Run workflow**:
   - **Rendering Strategy**:
     - `parallel-cluster` *(Recommended)*: Spins up **4 parallel cloud runners** (chunks `0-5850`, `5851-11700`, `11701-17550`, `17551-23401`), renders simultaneously at 60 FPS, and losslessly stitches them via FFmpeg into the master MP4.
     - `single-runner`: Renders the full 23,402 frames sequentially on one runner.
     - `hook-only`: Renders the 60-second teaser reel (3,600 frames) in ~3 minutes.
   - **GitHub Runner Hardware**:
     - `ubuntu-latest` (Default GitHub-hosted runner, 4 cores, 16 GB RAM)
     - `ubuntu-latest-8-cores` / `ubuntu-latest-16-cores` (GitHub-hosted high-spec runners)
4. Once completed, download the master video file from the **Artifacts** section!

### 1. Interactive Remotion Studio (Realtime Preview & Scrubbing)
```bash

```
Opens the Remotion Studio in your browser at `http://localhost:3000` where you can play, scrub through any frame, and preview all animations in real time.

### 2. Render 60-Second Viral Hook Reel (60 FPS, 3,600 Frames)
```bash

```
